Each county's final margin is estimated by filling in the vote types not yet counted: their volume from the expected early/mail share, their margin from the counted type ± the typical early-vs-Election-Day gap (2022 county vote-type data where available, otherwise state research). Feed vote-type splits are used where the state publishes them (GA, NC, SC, VA, KY); elsewhere the split is inferred from precincts reporting. "none" = no vote-type information for that state, so it is unadjusted.
